# CSS03 – CSS Styling Practice

A project created to practice CSS fundamentals as part of [The Odin Project](https://www.theodinproject.com/).

This project focuses on:

- Advanced CSS selectors
- Styling techniques such as margins, padding, and borders
- Experimenting with layouts and positioning

## Project Features

- Styled page with different typography, colors, and layout adjustments
- Demonstrates CSS properties like background, box model, and text alignment

## Technologies Used

- HTML
- CSS
